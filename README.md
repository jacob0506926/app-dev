
# Transformers

## About Transformers
**Transformers** is a popular science fiction franchise about giant robots that can transform into vehicles, machines, and other objects.

There are two main groups:

- **Autobots** - The heroes who protect Earth.
- **Decepticons** - The villains who want power and control.
